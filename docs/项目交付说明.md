# 项目交付说明

## 当前完成

- 简历解析、JD 解析、匹配分析、优化建议、面试题生成
- 岗位推荐、岗位搜索、职业规划、企业筛选
- 知识库上传、检索、调试、重处理
- 岗位数据源管理与同步

## 生产边界

- `mock` LLM / `mock` Embedding 用于演示和本地验证
- `csv/json/mock/api` 数据源支持本地演示和扩展接入
- `api` 数据源已支持基础鉴权刷新、分页、限流和重试回退，正式平台接入仍需按各家协议适配

## 知识库维护

- 种子数据位于 `docs/knowledge-seeds/`
- 导入脚本位于 `backend/scripts/import_knowledge_seeds.py`
- 支持 `txt/md/pdf/docx/doc`

## 验收建议

- 登录、上传、解析、分析、推荐、面试、规划、筛选全流程可跑通
- 知识库可上传、可检索、可重处理
- 数据源可创建、测试、同步、查看日志
- 离线环境可用 `LLM_PROVIDER=mock`、`EMBEDDING_PROVIDER=mock` 跑通评估脚本；真实 RAG 质量指标应在目标 embedding provider 下重建知识库后再采信
- 接口与部署文档可通过 `backend/scripts/export_delivery_docs.py` 一键导出
