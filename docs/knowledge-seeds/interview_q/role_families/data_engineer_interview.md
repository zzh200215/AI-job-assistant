## 数据｜窗口函数与分组取 TopN

- 题目：用 SQL 取每个部门薪资前 3 的员工，怎么写？
- 考察点：row_number、rank、dense_rank、分区排序、并列名次。
- 参考要点：ROW_NUMBER() OVER (PARTITION BY dept ORDER BY salary DESC) 编号；外层过滤序号小于等于 3；有并列时按业务选 rank 或 dense_rank；注意空值与重复。
- 追问：窗口函数和 group by 的本质区别是什么？

## 数据｜数仓分层与指标口径

- 题目：ODS、DWD、DWS、ADS 各自负责什么？
- 考察点：分层职责、清洗、主题聚合、口径唯一、复用。
- 参考要点：ODS 贴源；DWD 做明细清洗与规范化；DWS 按主题聚合；ADS 面向报表与应用；指标口径落在公共层并版本化；避免跨层反向依赖。
- 追问：什么情况下可以省略 DWD，直接做宽表？

## 数据｜Spark 与 Flink 的数据倾斜

- 题目：离线或实时任务出现数据倾斜，你怎么处理？
- 考察点：热点 key、加盐、广播、预聚合、反压。
- 参考要点：先看分区与 key 分布确认热点；热点 key 加随机前缀两阶段聚合；小表广播；聚合前预聚合；极端热点单独拆分处理。
- 追问：Flink 作业反压，你会从哪几个指标入手？

## 数据｜核心指标突然下跌的排查

- 题目：日活突然下跌 20%，你怎么判断是真跌还是数据问题？
- 考察点：埋点、ETL、口径、分群下钻、外部事件。
- 参考要点：先校验埋点上报与任务产出；对比上游表行数与延迟；按渠道、版本、地区、机型拆；对照转化漏斗；再看发布、活动与竞品事件。
- 追问：数据延迟和真实下跌同时存在时，怎么排优先级？
