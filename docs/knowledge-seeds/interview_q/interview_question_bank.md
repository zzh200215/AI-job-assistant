# 面试题库与准备指南

## Python 后端面试题

- Python 中装饰器、生成器、上下文管理器的使用场景是什么？
- FastAPI 和 Django 的差异是什么？如何做依赖注入和参数校验？
- MySQL 索引失效的常见原因有哪些？
- 如何设计一个简历上传、解析、匹配分析的后端接口？

## 系统设计面试

- 如何设计一个 RAG 知识库系统？
- 如何做文档切片、向量检索、BM25、多路召回、RRF 融合和重排？
- 如何设计任务中心，支持长任务进度、取消、失败重试？
- 如何处理高并发、限流、缓存和日志追踪？

## AI 算法岗面试

- Embedding、Rerank、召回、排序有什么区别？
- 推荐系统常见召回策略有哪些？
- NLP 模型评估指标有哪些？
- 如何评估 RAG 检索质量：Recall@K、MRR、Keyword Hit Rate。

## 行为面试 STAR 法

STAR 回答包括 Situation、Task、Action、Result。回答时要说明背景、目标、行动和量化结果。

## 手撕代码与技术面试技巧

准备数组、字符串、哈希表、动态规划、二叉树、数据库 SQL、接口设计题。回答时先确认边界条件，再给复杂度分析。
