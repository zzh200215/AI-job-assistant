# 后端工程师到架构师路径参考

## 目标画像

架构师不是单纯“懂得多”，而是能在复杂约束下完成技术取舍、组织协同和风险收敛。

## 演进阶段

### 初级到中级

- 写清晰、稳定、可测试的业务代码
- 掌握数据库、缓存、消息队列、网关等基础设施的使用
- 学会定位线上问题和做容量预估

### 中级到高级

- 负责核心模块设计
- 能从单服务扩展到系统视角思考
- 具备性能优化、稳定性建设和链路治理经验

### 高级到架构方向

- 能对业务增长、组织协作、技术债做整体规划
- 在高并发、高可用、成本控制之间做权衡
- 输出规范、平台能力和可复制方案

## 必备能力模块

- 系统设计
- 高并发与容量治理
- 数据建模与存储选型
- 异步架构与可靠性设计
- 团队协作与技术方案表达

## 对求职者的信号

- 主导过跨模块项目
- 能量化性能或稳定性收益
- 讲得清 trade-off，而不只是技术名词堆叠

## 推荐里程碑

- 做过一次从 0 到 1 的核心服务设计
- 做过一次从 1 到 N 的性能或稳定性治理
- 沉淀过技术规范、基础组件或平台能力
