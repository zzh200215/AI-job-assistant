# 技术与产品岗位简历模板参考

## Python 后端开发简历

适用于 Python 后端开发、FastAPI、Django、MySQL、Docker、RAG 项目经验候选人。

推荐结构：
- 个人优势：3 年 Python 后端开发经验，熟悉 FastAPI、Django、MySQL、Redis、Docker。
- 项目经验：写清业务背景、个人职责、技术方案、量化结果。
- RAG 项目：说明文档解析、向量检索、Query Rewrite、RRF 融合、重排、置信度评估。
- 技能关键词：Python、FastAPI、Django、SQLAlchemy、MySQL、Docker、Linux、API 设计。

项目经验表达模板：

负责智能招聘平台后端开发，基于 FastAPI 设计简历解析、岗位匹配、知识库检索接口；使用 MySQL 存储业务数据，Chroma 存储向量切片，Docker Compose 完成本地部署。通过异步任务中心提升长任务可观测性，将分析流程拆分为解析、匹配、面试、职业规划多个阶段。

## 前端工程师简历模板

适用于前端工程师、Vue、React、TypeScript、组件化、可视化页面候选人。

推荐结构：
- 技术栈：Vue 3、React、TypeScript、Vite、Pinia、Element Plus、Axios。
- 项目描述：突出复杂表单、权限路由、状态管理、错误处理、构建优化。
- 量化结果：页面加载速度、组件复用率、错误率下降、交互链路缩短。

## 产品经理简历优化建议

适用于产品经理、B 端 SaaS、用户调研、需求分析、PRD、数据驱动候选人。

推荐结构：
- 业务领域：B 端 SaaS、招聘平台、数据看板、企业筛选。
- 方法论：用户访谈、需求池管理、竞品分析、PRD、埋点、A/B 测试。
- 结果表达：转化率、留存率、线索量、处理效率。

## 应届生简历模板

应届生简历应突出课程项目、实习、竞赛、Git、SQL、基础工程能力。项目经验较少时，要把课程项目写成“目标、技术方案、个人贡献、结果复盘”四段式。

常见关键词：应届、校招、实习、课程项目、Web 开发、简单 ML、Python、Flask、SQL、Git、简历。
