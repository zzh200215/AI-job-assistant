# 常见岗位 JD 样例库

## Python 后端开发工程师

岗位职责：
- 负责后端 API、业务服务、数据模型和任务队列开发。
- 参与简历解析、岗位匹配、推荐、知识库检索等模块建设。
- 优化接口性能、稳定性、日志追踪和部署流程。

岗位要求：
- 3-5 年 Python 后端开发经验，熟悉 FastAPI 或 Django。
- 熟悉 MySQL、Redis、SQLAlchemy、Docker、Linux。
- 有 RAG、AI 工程化、异步任务、搜索推荐经验优先。

## AI 算法工程师

岗位职责：
- 负责 NLP、推荐系统、向量检索、模型评估与算法服务落地。
- 参与训练数据构建、模型调优、线上效果监控。

岗位要求：
- 熟悉 PyTorch、NLP、推荐系统、Embedding、Rerank。
- 有论文发表、算法竞赛、工业落地经验优先。

## 产品经理

岗位职责：
- 负责 B 端 SaaS 产品规划、需求分析、用户调研和 PRD 编写。
- 推动用户增长、数据分析、运营转化和跨团队协作。

岗位要求：
- 3-5 年 B 端产品经验，熟悉用户增长和数据驱动。
- 有技术背景、招聘平台、企业服务经验优先。

## 全栈开发工程师

岗位要求：
- 熟悉 React 或 Vue，同时具备 Node.js、Python 或 Java 后端能力。
- 掌握 PostgreSQL、MySQL、REST API、权限设计、部署运维。
- 有团队管理经验、全链路交付经验优先。

## 数据分析师与数据工程师

数据分析师要求 Python、SQL、Pandas、NumPy、数据可视化、业务分析、机器学习基础。

数据工程师要求 Spark、Flink、Hive、SQL、数据仓库、实时计算、ETL、数据质量治理。
