# DevOps 工程师能力模型

适用查询：DevOps 工程师必备技能、运维开发能力模型、云原生岗位要求、CI/CD 技能。

## 核心技能

- Linux 与网络：熟悉 Linux 系统、Shell 脚本、TCP/IP、DNS、负载均衡和常见故障排查。
- 容器与编排：掌握 Docker、Kubernetes、Helm、服务发现、滚动发布和弹性伸缩。
- CI/CD：能够设计构建、测试、制品管理、部署、回滚和灰度发布流水线。
- 可观测性：理解日志、指标、链路追踪、监控告警、SLO、故障演练和容量规划。
- 自动化：至少掌握 Python、Go 或 Shell，能编写自动化运维、巡检和发布工具。

## 云原生岗位要求

云原生 DevOps 需要理解基础设施即代码、配置管理、密钥管理、多环境隔离、成本优化和安全基线。高级候选人应具备稳定性治理、应急响应和平台工程经验。

## 简历与面试评估要点

简历应强调平台规模、集群数量、发布频率、故障恢复时间、自动化覆盖率和成本优化结果。面试常围绕 Kubernetes 调度、服务发布、监控告警、线上故障定位和 CI/CD 设计展开。
