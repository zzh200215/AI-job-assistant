# 岗位能力模型与技能树

## 后端开发能力模型

核心能力：
- 编程语言：Python、Java、Go 至少一门深入。
- Web 框架：FastAPI、Django、Spring Boot。
- 数据库：MySQL、PostgreSQL、Redis、索引优化、事务。
- 工程能力：Docker、Linux、日志、监控、测试、CI/CD。
- 系统设计：缓存、队列、限流、幂等、异步任务、微服务。

## AI 工程师能力模型

核心能力：
- 机器学习基础、深度学习、PyTorch、NLP、推荐系统。
- Embedding、向量数据库、RAG、Rerank、模型评估。
- AI 工程化：Prompt、结构化输出、成本控制、灰度发布。

## 产品经理技能树

核心能力：
- 用户调研、竞品分析、需求分析、PRD、原型设计。
- 数据分析、用户增长、转化漏斗、A/B 测试。
- B 端 SaaS 产品需要理解权限、流程、组织协作和交付价值。

## DevOps 工程师能力模型

核心能力：
- Linux、Docker、K8s、CI/CD、监控告警、日志平台。
- 至少掌握一门编程语言，能编写自动化脚本。
- 理解云原生、弹性伸缩、发布回滚和故障恢复。

## 数据科学家与数据工程师能力

数据科学家需要统计学、机器学习、特征工程、模型评估和业务解释能力。

数据工程师需要 Spark、Flink、Hive、SQL、数据仓库、实时计算、数据质量治理。
