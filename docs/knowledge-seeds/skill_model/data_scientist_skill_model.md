# 数据科学家核心能力要求

适用查询：数据科学家核心能力、数据科学岗位技能、机器学习建模能力、数据科学家面试准备。

## 核心能力

- 统计学基础：掌握概率分布、假设检验、置信区间、回归分析、因果推断和实验设计。
- 机器学习：熟悉分类、回归、聚类、排序、推荐、特征工程、模型调参和模型评估。
- 编程与工具：熟练使用 Python、SQL、Pandas、NumPy、Scikit-learn、PyTorch 或 XGBoost。
- 业务解释：能把模型结果转化为业务洞察，说明指标变化、关键特征和可落地策略。
- 实验评估：理解离线评估、线上 A/B 测试、数据泄漏、样本偏差和模型监控。

## 岗位分层

初级数据科学家重点考察数据清洗、特征工程、SQL 和基础建模。中高级候选人需要具备复杂业务建模、指标体系建设、实验设计、模型上线协作和业务影响评估能力。

## 简历与面试评估要点

简历应突出业务问题、数据规模、建模方法、核心指标提升和上线效果。面试常考统计推断、机器学习算法原理、特征工程、模型评估和业务 case 拆解。
