# 全栈开发工程师能力模型

适用查询：全栈开发岗位招聘要求、全栈工程师技能树、前后端一体化开发能力、全栈岗位能力模型。

## 核心能力

- 前端开发：掌握 Vue 或 React、组件化、状态管理、路由、工程化、性能优化和前端测试。
- 后端开发：熟悉 Python、Java、Go 或 Node.js，理解 RESTful API、鉴权、缓存、异步任务和数据库设计。
- 数据库与中间件：能使用 MySQL、PostgreSQL、Redis、消息队列和对象存储完成业务闭环。
- 工程交付：理解 Docker、CI/CD、日志监控、错误追踪、接口文档和自动化测试。
- 产品意识：能根据业务目标快速拆解需求，独立完成从页面到接口到数据落库的端到端交付。

## 岗位要求

全栈岗位通常要求候选人能在资源有限或快速迭代场景中独立推进功能落地。高级全栈工程师还需要具备架构拆分、性能瓶颈定位、安全设计和团队协作能力。

## 简历与面试评估要点

简历应突出端到端项目、独立负责范围、技术栈组合、性能优化和业务结果。面试常考前端工程化、接口设计、数据库建模、部署发布和复杂业务拆解。
