# 数据分析师岗位技能需求

适用查询：数据分析师岗位技能需求、数据分析岗位要求、BI 分析师能力模型、数据分析师求职准备。

## 核心技能

- SQL：能够编写复杂查询、窗口函数、聚合分析、留存分析、漏斗分析和数据校验脚本。
- 指标体系：理解北极星指标、过程指标、业务看板、维度拆解和异常归因。
- 分析方法：掌握描述性分析、对比分析、分群分析、路径分析、A/B 测试和同期群分析。
- 工具能力：熟悉 Excel、Python、BI 工具、可视化图表和自动化报表。
- 业务沟通：能把数据结论转化为业务建议，推动运营、产品、销售或增长团队行动。

## 岗位要求

数据分析师不仅要取数和做报表，还要解释指标变化原因，定位业务问题，并提出可验证的优化方案。高级分析师需要具备专题分析、实验设计、数据治理和跨部门推动能力。

## 简历与面试评估要点

简历应突出分析主题、使用的数据口径、关键发现、行动建议和最终指标变化。面试常考 SQL、指标拆解、业务 case、A/B 测试和数据异常排查。
