# 产品经理能力模型与技能树

适用查询：产品经理技能树、产品经理核心能力、B 端产品经理能力模型、产品经理求职竞争力。

## 核心能力

- 需求分析：能从用户访谈、业务流程、数据反馈中识别真实问题，拆解需求优先级。
- PRD 与原型：能够输出清晰的产品需求文档、业务流程图、信息架构和交互原型。
- 数据分析：掌握转化漏斗、留存、活跃、A/B 测试、埋点设计和指标归因。
- 协同推进：能与研发、设计、测试、运营、销售和交付团队对齐目标、排期和验收标准。
- 商业理解：理解业务模式、客户价值、成本收益、竞品格局和产品定价逻辑。

## B 端产品经理重点

B 端 SaaS 产品经理需要特别关注权限体系、组织架构、审批流程、数据隔离、客户实施和交付价值。优秀候选人通常能把复杂业务流程抽象为可配置能力，并用指标说明上线后的效率提升。

## 简历与面试评估要点

产品经理简历应突出负责的模块、目标用户、关键决策、跨团队协作和量化结果。面试中常考需求取舍、竞品分析、异常场景设计、指标体系和项目复盘。
