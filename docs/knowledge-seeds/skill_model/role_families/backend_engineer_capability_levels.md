## 后端工程师｜初级能力锚点

- 核心能力：掌握一门后端语言与主流框架；会写 CRUD 和基础 SQL；理解 Git、HTTP、日志与单元测试。
- 典型证据：在指导下独立完成一个模块；能读懂现有接口并补测试；能按规范提交可运行的代码。
- 评估锚点：给定明确需求，能拆出接口与表结构，覆盖正常和异常路径。
- 常见短板：边界条件考虑不足；说不清索引、事务和并发。

## 后端工程师｜中级能力锚点

- 核心能力：独立设计模块；掌握 MySQL 索引与事务、Redis 缓存、消息队列、接口幂等与测试；能做容量估算。
- 典型证据：负责过核心接口上线；用执行计划优化过慢查询；处理过线上告警并完成复盘。
- 评估锚点：能给出数据模型、接口契约和失败重试方案，并对可用性与成本负责。
- 常见短板：只谈框架用法；对锁、重试风暴和降级边界说不清。

## 后端工程师｜高级能力锚点

- 核心能力：系统设计与技术选型；高并发与稳定性治理；跨团队推进；能识别并偿还技术债。
- 典型证据：主导过一次高并发或高可用改造；设计过可回滚的迁移方案；推动多个团队统一接口或数据口径。
- 评估锚点：能在约束下做取舍，量化容量、故障半径与迁移成本，并对最终结果负责。
- 常见短板：方案过大不可落地；忽略组织成本与灰度路径。
