## 测试工程师｜核心能力锚点

- 核心能力：用例设计；接口测试；自动化脚本；缺陷定位与跟踪；回归策略。
- 典型证据：负责过模块测试方案；搭建过接口自动化；推动缺陷根因修复。
- 评估锚点：能基于风险设计测试范围，用可重复手段覆盖核心路径。
- 常见短板：只做手工点击；用例缺少边界与异常。

## 测试工程师｜进阶能力锚点

- 核心能力：性能测试；安全测试基础；测试平台；质量门禁；稳定性治理。
- 典型证据：做过压测与容量评估；把自动化接入 CI；建立过质量指标与门禁。
- 评估锚点：能用数据衡量质量风险，把测试前移并控制发布风险。
- 常见短板：追求覆盖率数字；忽略场景与数据真实性。

## 安全工程师｜核心能力锚点

- 核心能力：OWASP 常见漏洞；渗透测试基础；代码审计；日志与应急响应。
- 典型证据：发现并推动修复过高危漏洞；做过安全基线检查；参与过事件处置。
- 评估锚点：能识别业务链路中的真实攻击面，并给出可落地的修复优先级。
- 常见短板：只会扫工具；说不清业务影响与修复成本。

## 安全工程师｜进阶能力锚点

- 核心能力：威胁建模；SDL；零信任与权限体系；数据安全；合规要求。
- 典型证据：在架构评审中落地过安全设计；建立过漏洞管理流程；推动过权限最小化。
- 评估锚点：能把安全要求嵌入研发流程，平衡风险、体验与交付效率。
- 常见短板：安全与业务对立；缺少度量与持续运营。
