## DevOps 工程师｜初级能力锚点

- 核心能力：Linux 与网络基础；Docker；CI/CD；Shell 或 Python 自动化；基础监控。
- 典型证据：能独立部署服务；编写发布脚本；处理常见磁盘、端口和权限问题。
- 评估锚点：给定服务，能完成可重复的构建、部署与回滚。
- 常见短板：手工操作多；缺少变更记录与回滚验证。

## DevOps 工程师｜中级能力锚点

- 核心能力：Kubernetes；发布策略；监控告警；容量与成本；故障处理。
- 典型证据：维护过生产集群；设计过滚动发布与回滚；优化过资源配额或告警质量。
- 评估锚点：能对发布安全、资源利用和故障恢复时间负责。
- 常见短板：堆工具；说不清 SLO、容量和故障半径。

## SRE｜高级能力锚点

- 核心能力：SLO 与错误预算；稳定性架构；故障演练；应急体系；跨团队治理。
- 典型证据：定义过核心服务 SLO；主导过故障演练或容灾切换；推动架构改造降低故障率。
- 评估锚点：能用数据管理可靠性投入，把稳定性要求变成可执行的工程决策。
- 常见短板：只做救火；没有预防性投入与复盘闭环。
