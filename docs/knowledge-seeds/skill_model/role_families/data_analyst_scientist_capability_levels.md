## 数据分析师｜核心能力锚点

- 核心能力：SQL 与可视化；指标体系；业务拆解；实验分析；结论表达。
- 典型证据：独立完成专题分析；定位过指标异常；推动分析结论进入业务动作。
- 评估锚点：能把业务问题转成可验证的数据问题，并给出可执行建议。
- 常见短板：堆图表；相关当因果；结论没有行动项。

## 数据科学家｜核心能力锚点

- 核心能力：统计与概率；特征工程；模型训练与评估；上线监控；业务解释。
- 典型证据：完成过模型从数据到上线；做过离线与线上指标对齐；处理过特征漂移。
- 评估锚点：能选择合适模型并说明收益、风险与可解释性，对线上效果负责。
- 常见短板：只追离线分数；忽略样本偏差与上线成本。
