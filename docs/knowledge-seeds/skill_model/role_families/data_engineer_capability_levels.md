## 数据工程师｜初级能力锚点

- 核心能力：熟练 SQL；理解 ETL 流程、调度依赖、数据校验与基础建模。
- 典型证据：独立开发与维护数据任务；能定位任务失败与数据延迟；按规范补齐数据文档。
- 评估锚点：给定报表需求，能写出正确、可调度、可复跑的加工链路。
- 常见短板：只关注跑通；对口径、幂等和回补考虑不足。

## 数据工程师｜中级能力锚点

- 核心能力：数仓分层与维度建模；Spark 或 Flink 开发；数据质量、成本与任务 SLA。
- 典型证据：负责过主题域建设；优化过倾斜或长尾任务；建立过数据质量规则与告警。
- 评估锚点：能设计可复用、可追溯的数据模型，并对时效、成本和质量负责。
- 常见短板：模型堆宽表；缺少血缘、口径版本与回滚方案。

## 数据工程师｜高级能力锚点

- 核心能力：实时与离线一体化架构；数据治理；稳定性与成本体系；跨团队数据产品推进。
- 典型证据：主导过实时数仓或治理专项；定义过公司级指标口径；设计过容灾与回补方案。
- 评估锚点：能在业务增长下控制数据链路复杂度、成本与故障半径。
- 常见短板：只做平台不讲业务价值；治理动作没有落地机制。
