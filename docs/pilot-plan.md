# Pilot 客户接洽与实施计划 —— 第二个客户 Pilot（T5-2）

> 版本：v1.0（T5-2 准备材料）
> 日期：2026-08-01
> 目的：给商务与实施人员一份可执行手册，覆盖「找谁 → 怎么说 → 签什么 → 怎么实施 → 怎么记录工时」。
> 目标量化指标：**第二个客户实施成本 ≤ 第一个客户的 40%**（配置化交付的核心验证）。
> 配套：`docs/pilot-report.md`（Pilot 结束填写）、`docs/定价表.md`（报价）、`test-release-checklist.md`（Pilot 环境回归）。

## 2. 接洽清单（商务侧）

### 2.1 会前准备
- [ ] 一份 `docs/产品白皮书.md`（电子版 + 打印版）
- [ ] 演示环境就绪（`docs/演示脚本.md` 的 1 分钟进场已跑通）
- [ ] 定价基线（`docs/定价表.md`，Pilot 低价方案见 §3.3）
- [ ] 明确本次 Pilot 免费/低价、数据反馈约定、实施支持范围

### 2.2 沟通要点（按此顺序讲）
1. **价值定位**：不是招聘网站，是「AI 就业服务中台」——客户获得自有品牌、自有知识库、自有套餐体系的一站式就业服务平台；
2. **能力演示**：求职者全流程 → RAG 亮点 → 双租户白标对比（`docs/演示脚本.md` 流程）；
3. **差异化**：Agentic RAG（检索路由 + 多路召回 + 可解释可评测）+ 多智能体协作（任务可追踪）+ 企业级治理（审计/SSO/AI 发布门禁）；
4. **商务**：Pilot 低价 + 数据反馈约定（§3.3），正式定价见 `docs/定价表.md`。

### 2.3 客户常见异议应答
| 异议 | 应答 |
| --- | --- |
| "数据放你们平台安全吗？" | 行级租户隔离 + 审计日志 + 可选私有化部署；Pilot 阶段数据仅用于本次验证与优化 |
| "能接我们自己的内容吗？" | 8 类知识源批量导入（txt/md/pdf/docx），导入即参与 RAG 检索 |
| "要多久能上线？" | 配置化交付 0.5 天；Pilot 全程我方实施，客户只需提供素材 |
| "接入真实大模型要什么？" | 我方统一接入 OpenAI 兼容 / DashScope，客户无感 |

## 3. Pilot 合同要点（法务起草，此处给条款骨架）

| 条款 | 要点 |
| --- | --- |
| 合同性质 | Pilot 合作协议（期限 3 个月，可转正） |
| 费用 | 低价 / 免费 + 转正式后抵扣（Pilot 期 ¥X,XXX 或 0，见 §3.3） |
| **数据反馈约定** | 客户授权平台收集**脱敏**使用数据（功能使用量、额度消耗、转化漏斗、留存），用于产品优化与定价验证；**不含**简历正文、个人身份信息 |
| 数据安全 | 行级租户隔离承诺；Pilot 结束按约定导出或删除数据 |
| 知识产权 | 平台知识产权归我方；客户导入内容归客户；源码复用边界见《技术复用补充协议》 |
| 实施支持 | 我方负责：建租户、配品牌、配套餐/题库、导岗位库与知识、种子数据迁移、培训 |
| 退出机制 | 提前 30 天书面通知；数据导出/删除条款 |

### 3.3 Pilot 定价方案（建议）
- 高校就业办：Pilot 期 **免费 3 个月**，转正式按 `docs/定价表.md` 教育折扣（如 Pro ¥9,800 → Pilot 转正 ¥6,800/年）；
- 培训机构：Pilot 期 **¥3,000 / 3 个月**，转正式抵扣；
- 双方约定 Pilot 期产出至少 1 份数据反馈（功能使用报告）。

## 4. 实施流程演练（Pilot 环境，记录每步耗时）

> 目标：全程 ≤ 0.5 人·天；每步记录耗时，填入 §6 工时表。
> 数据基线：首个客户（本项目）实施投入估约 N 人·天（Pilot 结束后按本表实测对比，目标 ≤40%）。

### 4.1 建租户
- [ ] `POST /admin/tenants`：name / slug / industry / plan_tier / expires_at
- [ ] 通过前端「运营后台 → 租户管理」确认租户出现在列表

### 4.2 配品牌
- [ ] `PUT /admin/tenants/{id}/brand`：logo_url / primary_color / brand.company / brand.contact（可选 favicon / login_bg）
- [ ] 前端登录页刷新确认白标生效（A/B 对比验证）

### 4.3 配域名（可选）
- [ ] `POST /admin/tenants/{id}/domains` 绑定主域名，`is_primary=1`
- [ ] DNS 解析到前端；未解析则用前端地址 + 租户切换验证

### 4.4 配套餐与题型
- [ ] `POST /subscription/admin/plans`：按客户要求自定义 pro 套餐名/价格/权益
- [ ] 题库配置：`InterviewQuestionBank`（按 tenant 覆盖 tech/hr/comprehensive/stress/group 题型模板或静态题）
- [ ] 评分配置：`InterviewScoringRule`（按 tenant 配置维度与权重）
- [ ] 前端订阅页确认自定义套餐展示

### 4.5 导入岗位库
- [ ] `POST /admin/tenants/{id}/jobs`：批量导入客户 JD（title/raw_text 必填）
- [ ] 岗位搜索 / 推荐页确认岗位仅出现在该租户

### 4.6 导入知识库
- [ ] `POST /admin/tenants/{id}/knowledge`：上传客户文档（txt/md/pdf/docx，指定 doc_type）
- [ ] 或 `python scripts/import_knowledge_seeds.py` 导入平台种子知识
- [ ] 知识库检索确认命中客户内容

### 4.7 迁移种子数据
- [ ] 创建客户管理员账号（`create_admin.py` 或注册后提升角色）
- [ ] 迁移样例数据：示例简历、公开 JD、种子知识（确认不跨租户可见）
- [ ] 双租户隔离验证：A 租户数据 B 租户不可见

### 4.8 环境验收
- [ ] 跑通 `test-release-checklist.md` §6 Pilot 环境回归全部条目
- [ ] 客户管理员可在运营后台自助查看租户状态/报表
