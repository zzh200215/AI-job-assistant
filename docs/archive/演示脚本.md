# 演示脚本 —— 智能招聘与职业规划平台（双租户白标）

> 版本：v1.0（T5-1）
> 日期：2026-08-01
> 目标观众：院校 / 培训机构 / 企业决策人
> 演示时长：约 12 分钟（可裁剪为 8 分钟精华版）
> 核心卖点：**一份部署、千家客户；客户无感"这是一套 SaaS 平台"**

## 0. 演示环境

| 项 | 说明 |
| --- | --- |
| 前端地址 | `http://localhost:5173`（本地）；生产 `<服务器IP>/` |
| 后端 API | `http://localhost:8000/api`（本地，Swagger: `/docs`） |
| 管理员账号 | `demo_admin@example.com`（密码见 `.env` 或部署时设置） |

```bash
# 后端
cd backend && python -m uvicorn app.main:app --reload --port 8000

cd frontend && npm run dev

cd backend && python scripts/import_knowledge_seeds.py
```

> 本地演示默认 mock 模型，无需 API Key；接入真实模型可提升演示效果。

## 1. 开场（0–1 分钟）

> **话术**：今天演示的不是又一个招聘网站，而是一套**可配置、可白标、可计量**的 AI 就业服务中台。核心问题：如何让高校/机构在半小时内，拥有一个**带自己品牌、自己知识库、自己套餐体系**的就业服务平台？

**演示动作**：打开前端登录页（A 租户品牌入口）——展示客户视角的白标外观。

---

## 2. 求职者全流程（2–5 分钟）

以求职者视角走一遍完整闭环（A 租户内体验）：

| 步骤 | 页面 | 演示点 |
| --- | --- | --- |
| ① 注册/登录 | 登录页 | 白标外观、用户体系 |
| ② 上传简历 | 简历上传 | PDF/Word 解析、结构化展示 |
| ③ 智能分析 | 智能分析 → 分析详情 | **多智能体协作**：匹配度 + 能力差距 + 优化建议 + 面试题 + 职业建议 |
| ④ 模拟面试 | 面试室 → 面试报告 | WebSocket 实时问答、逐题评分、复盘报告 |
| ⑤ 岗位推荐 | 岗位搜索 / 岗位推荐 | 基于简历的混合推荐、投递流程 |
| ⑥ 职业规划 | 职业规划工作台 | 能力雷达、成长路线图、阶段诊断 |

**讲解重点（面试官/客户最关心）**：
- 打开「任务中心」展示**多智能体协作**：每个 Agent 步骤可追踪、RAG 检索引用可回看（强调"不是黑盒 AI，每一步有依据"）；
- 打开「Agent 分析」展示 Agentic RAG 检索证据与置信度。

---

## 3. 知识库与 RAG 亮点（5–7 分钟）

**演示动作**：
- 打开「知识库」，展示 8 类知识源（简历模板 / 岗位 JD / 面试题库 / 能力模型 / 行业报告 / 职业路径 / 薪资市场 / 转行指南）；
- 打开「知识库 → 高级调试」，现场提问一个问题，展示**多路召回 + RRF 融合 + Rerank** 的检索路径与命中来源；
- 展示「评测报表」页面：RAG recall@5 / MRR 指标与历史快照对比。

> **话术**：普通 RAG 是"全捞一遍再筛"，我们的 **Retrieval Planner** 先让模型判断该查哪些知识、各取几条，再多路召回融合重排。回答质量更高，还能量化——这就是白皮书里"匹配准确率 XX%"的来源。

---

## 4. 多租户白标（7–9 分钟）—— 本次演示核心

**演示动作**（切到平台管理员 `demo_admin`）：

1. 进入「运营后台 → 租户管理」，展示租户列表（A/B 两租户，带到期倒计时 tag）；
2. 点击 **A 租户（示例大学就业中心）**：
   - 展示品牌配置（logo / 主色 / 行业 / 域名绑定）；
   - 展示套餐（pro）与到期时间；
3. 现场演示**配品牌**：改 A 租户主色，回到前端登录页 → 刷新，**品牌色即时生效**；
4. 切回 B 租户（默认视角），前端登录页显示默认品牌——形成 A/B 对比，强调"客户无感 SaaS"。

> **话术**：A 是客户视角——它有自己名字、logo、主色、专属域名；B 是默认视角。两者数据行级隔离，互不可见。客户看到的是自己的平台，我们管的是同一份部署。

---

## 5. 订阅与计费闭环（9–11 分钟）—— 展示运营成熟度

**演示动作**（运营后台）：

1. 打开「租户管理 → 续费」，给 A 租户续费 6 个月 → 展示到期时间顺延、订阅状态恢复；
2. 打开「租户级报表」（Overview 页），展示：
   - **转化漏斗**（注册 → 上传简历 → 分析 → 面试 → 投递 五步）；
   - **留存** 与 **营收汇总**（按租户、按套餐）；
3. 强调 T4 能力：到期租户**自动停用订阅**、续费即时恢复（小时级调度兜底）。

---

## 6. 收尾与互动（11–12 分钟）

**收尾话术**：
- 安全：JWT + bcrypt、登录限流、审计日志、飞书 SSO、AI 发布门禁、备份恢复脚本——企业级治理基础就绪；
- 商务：`docs/定价表.md` 三档报价（白标 SaaS / 私有化 / 未来 API 开放）；
- 实施：配置化交付，第二个客户上线成本 ≤ 第一个客户的 40%。

**Q&A 弹药**：
- "能接我们自己的知识吗？" → 能，8 类知识源批量导入（txt/md/pdf/docx），导入即参与 RAG 检索；
- "数据安全怎么保证？" → 行级租户隔离 + 审计 + 私有化部署选项；
- "接入真实大模型要什么？" → 配一个 API Key（OpenAI 兼容 / DashScope）；
- "多久能上线？" → 一个租户 0.5 天自助配置。
