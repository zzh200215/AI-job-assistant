# 统一交付手册

最后更新：2026-06-26

本手册用于把当前项目的交付范围、运行方式、演示边界、验证方法和关键入口收敛到一份文档中。

## 1. 项目定位

- 技术主线：`Agentic RAG + 岗位推荐 + 面试模拟 + 推荐评测 + LLMOps`
- 交付目标：达到“可演示、可答辩、可验证、可说明”的项目状态
- 当前形态：课程 / 毕设级可交付系统，非真实生产级招聘平台

## 2. 已交付能力

### 候选人侧

- 简历上传、解析、查看、优化版生成、导出
- JD 输入与详情查看
- 智能分析结果页
- 职业规划
- 岗位搜索、岗位推荐
- AI 模拟面试与面试报告

### 招聘者侧

- 企业筛选工作台
- 候选人筛选记录保存、导出、预览
- 数据源管理、测试、同步、日志查看

### 平台治理与可观测

- Prompt 追踪页
- Agent / RAG 追踪看板
- 任务中心
- 推荐评测看板
- 推荐调优样本导出
- 推荐权重配置与调权实验对比
- RAG / Agent 离线评测报表页
- 系统状态页

## 3. 重点新增收口

### 图片版简历 OCR

- 已支持 `PNG / JPG / JPEG` 图片简历上传
- 已支持扫描件 PDF 在 OCR 可用时自动识别
- 上传页会展示当前 OCR 能力是否开启
- 若 OCR 未开启，会返回明确的友好提示

### 推荐反馈闭环

- 已支持 `like / dislike` 落库
- 已支持反馈趋势、岗位 / 简历 / 行业分布
- 已支持高分点踩、低分点赞异常识别
- 已支持调优样本预览与 `CSV / JSON` 导出
- 已支持推荐权重配置与实验对比

### LLMOps 轻量闭环

- 已支持 prompt 版本标记、汇总、对比、回放
- 已支持按 `task_id / analysis_record_id` 深链查看 trace
- 已支持从任务中心 / Agent 页面跳转到对应 trace

### 评测可视化

- 已支持离线评测报告持久化到 `backend/reports/`
- 已支持时间戳历史快照
- 已支持前端查看最新报告、历史报告、两次报告差异

## 4. 运行方式

### 本地启动

后端：

```bash
cd backend
copy .env.example .env
python -m uvicorn app.main:app --reload --port 8000
```

前端：

```bash
cd frontend
npm install
npm run dev
```

### 关键环境变量

- `MYSQL_PASSWORD`
- `JWT_SECRET`
- `LLM_*`
- `EMBEDDING_*`
- `APP_ENV`
- `APP_DEBUG`

详见：[setup-and-security.md](D:/AI/python/基于Agentic%20RAG与多智能体协作的智能招聘与职业规划平台/docs/setup-and-security.md)

## 5. 演示边界

- `mock` LLM / `mock` Embedding 仅用于本地演示与验证
- `api` 数据源已支持基础鉴权刷新、分页、频控和失败回退；真实第三方平台正式接入仍需按各家协议适配
- 当前异步任务已支持线程池与独立 Redis worker；未引入 Celery / ARQ 这类完整分布式编排框架
- 项目结论可用于演示和答辩，不等同于真实招聘决策

## 6. 验证方式

### 基础验证

- 后端：`pytest`
- 前端：`npm run build`

### 评测验证

```powershell
./scripts/eval-quality.ps1
```

执行后会生成：

- `backend/reports/rag_eval_*.json`
- `backend/reports/agent_eval_*.json`
- `backend/reports/rag_eval.json`
- `backend/reports/agent_eval.json`

### OCR 验证

- 上传 `png/jpg/jpeg` 图片简历
- 或上传扫描件 PDF
- 若系统状态页显示 OCR 开启，则应可进入解析流程
