## 2. 被追问时的四句话

1. **失败 ≠ 空**：首页「今日任务」今天真的 500 过——`utc_now()` 是 aware，MySQL 读回 naive，相减抛 `TypeError`。已改成 `utc_now_naive()`，并加了 `test_dashboard_today_tasks` 回归；现在显示的是两条真任务，不是 0。
2. **加载 ≠ 空**：排队、执行、失败、超时各有自己的措辞；`pending` 不会被说成“正在逐节生成”。
3. **mock / 真实可辨识**：`LLM_PROVIDER=mock` 有顶部提示条；每次分析有 provenance（几发调用、谁答的、几发失败）。不把 57 说成真模型质量。
4. **点得到 = 做得到**：阶段流转前后端同源；非法流转拦下；终态有阶段历史才能撤销。

## 3. 别说 / 别点

- 别把 **57 分**说成真实模型质量：本地是 mock + 六维规则，顶部已经写明。
- 别等满 10 题；只演第一题 + 一次提交。
- 别打开 `/eval-reports`：该页只统计 `rag/agent/recommend/parse` 四类报告，当前库里没有可展示的报表。
- 法析智鉴的 `Top-5 +15%`、`40 分钟→5 分钟` 还没有在本仓库核实；没带源材料时不要主动讲。
- `agent_eval` 的 `MAE 3.0 / hit 10/10` 是旧 10 对基线，不要说成当前 25 对的指标；简历里也没写。

## 4. 数字口径

- 本地演示：57 分、84 完整度、5 发 mock 调用、2 个今日动作、5 条投递。
- 评测：RAG 50 条查询 `Recall@5 0.920 / MRR 0.922`；匹配集 25 对，设 MAE/Spearman 离线门槛。
- 测试：后端全量 **1631 passed / 0 failed**（2026-11-25，192.59s；含新增 4 条：SummaryAgent 3 + 今日待办 1）；前端 825 条 / 静态守卫 57 / 首屏 406 kB（Element Plus 239 kB，预算 420）。
- 运行：`scripts/local-demo.ps1` 一条命令启动 mock + thread，不需要另起 worker；`-Stop` 只停 8001/5173 的监听进程。
