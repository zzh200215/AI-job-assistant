# 知识库维护与验证说明

## 可导入内容

- `resume_template` 简历模板
- `jd_lib` 岗位 JD 样例
- `interview_q` 面试题库
- `skill_model` 能力模型
- `industry_report` 行业报告
- `career_path` 职业路径
- `salary_market` 薪资市场资料
- `transition_guide` 转行指南

## 导入方式

```bash
cd backend
python scripts/import_knowledge_seeds.py
```

按目录增量导入：

```bash
cd backend
python scripts/import_knowledge.py ../docs/knowledge-seeds/career_path --doc-type career_path --recursive
```

## 更新流程

1. 将新文档放入 `docs/knowledge-seeds/` 或通过前端上传
2. 执行导入或在知识库页面上传
3. 在知识库页面查看切片、检索结果和 Query Rewrite 调试
4. 如切片失败，执行重处理

## 验证方法

- 普通检索：确认关键词能召回对应文档
- 高级调试：确认改写 query、召回切片、RAG 置信度正常
- 智能分析结果页：确认有参考知识来源展示
