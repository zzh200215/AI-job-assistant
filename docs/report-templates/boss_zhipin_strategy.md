# BOSS 直聘投递策略

评估报告第五节的**直接来源**。这一节不经过模型：内容不依赖某一份简历，让模型复述只会引入编造风险，
也白花一次调用。渲染器按 `## ` 标题切节，逐字引用第一至五节。

这份文件**不进 RAG 语料**（`scripts/import_knowledge_seeds.py` 的 `SEED_MAPPINGS` 里没有它）：
它是版式固定的成稿素材，不是检索候选；放进语料会让每条路由的召回候选多一项，
把 RAG 那三条形门（recall / MRR / keyword_hit）往没人验证过的方向挪。

---

## 1. 先诊断：邀约不足的常见根因

| 根因 | 表现 | 自检 |
| --- | --- | --- |
| 画像不完整 | 在线简历空白、无职业照、未传 PDF | HR 端打开率 <30% |
| 话术模板化 | 「您好，我对岗位感兴趣」群发 | 回复率 <5% |
| 到岗时间/调剂模糊 | 空着或不填 | 推来不匹配岗 |
| 时机错误 | 周末晚、通勤高峰发 | 瞬间被淹没 |
| 只投不看标签 | 不筛「活跃」 | 命中率低 |

## 2. 投递前：把画像和简历「喂」到位

完善 BOSS 在线简历：清晰职业照、学历/经验完整、求职意向精确到方向（如「大模型应用开发 / RAG」）。

上传 **PDF 附件简历**（与第三节批改稿的净稿一致），防排版乱码。

到岗时间、是否接受调剂写清楚。

## 3. 打招呼话术：把匹配度「喂」到 HR 眼前（核心）

**模板（按 JD 微调关键词，占位符保持原样不要填）**：

您好，我注意到贵司招聘【岗位名】，我有【N 年】大模型应用开发经验，做过【与 JD 匹配的 1–2 个核心项目，含量化成果】，例如【一句话项目亮点 + 数字】。附件是我的简历，期待沟通！

⚠️ 话术里的项目表述**按你真实的角色写**：是主导就写主导，是参与就写「参与 / 负责其中 XX 模块」——**不要为了好听把参与说成主导**，面试一追就穿。

规则：

1. 每条必须**针对 JD 关键词**改 2–3 个词，禁止群发同一句。
2. 准备 2–3 个简历版本（偏 RAG / 偏 Agent / 偏部署），投递时按岗位微调。
3. 把第三节里的「个人优势」段浓缩成「在线简历一句话标签」，强化第一眼匹配。

## 4. 投递节奏与筛选

**黄金时段**：工作日 **9:00–11:00**、**14:00–16:00**；避开周末晚上与早晚通勤高峰。

优先筛选带 **「刚刚活跃」「今日回复」「老板直招」** 标签的岗位，回复率最高。

每日 **15–25 个有效岗位**（非海投）；老板直招优先于 HR 代发。

标记明显不匹配岗位，减少系统无效推荐。

## 5. 跟进与转化

已读不回：2–3 天后补一句，附 **作品集 / GitHub / Demo 链接** 或证书截图：「补充一份项目 Demo 链接，方便您快速了解我的实操能力」。

收到面试：1 小时内确认，问清地址 / 流程 / 需带材料。

关注「被查看 → 被邀约」转化率，低于 10% 则**优化打招呼话术**而非继续海投。
