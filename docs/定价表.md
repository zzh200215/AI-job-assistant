## 1. 定价三维总览

| 维度 | 说明 |
| --- | --- |
| 用户量 | 租户下注册用户数 / 并发活跃用户数 |
| 租户数 | 订阅的租户（品牌实例）数量 |
| 功能包 | free / pro / enterprise 三档权益矩阵 |

> 白标 SaaS 按「租户年费 + 用户量档位」计价；私有化按「一次性授权费 + 年维护费」计价；API 开放（M6，规划中）按调用量计价。

## 3. 白标 SaaS 报价（院校 / 培训机构）

按年订阅，包含品牌白标、自定义域名、知识库托管与运营后台自助配置。

| 档位 | 年费（¥） | 包含用户数 | 超出用户单价 | 说明 |
| --- | --- | --- | --- | --- |
| **基础版（free）** | ¥0 | ≤ 50 | — | 试用体验，无白标 |
| **Pro 版** | ¥9,800/年 | ≤ 300 | ¥20/人/年 | 单租户，完整权益 + 基础白标 |
| **企业版** | ¥29,800/年 | ≤ 1,000 | ¥15/人/年 | 多管理员、组织级知识库、专属支持 |
| **定制版** | 面议 | 1,000+ | — | 私有化 / 高安全（独立 schema 预留）/ 定制开发 |

> 用户量档位说明：以租户内**注册用户数**计费，超出部分按档递加，次年按实际用量复核。院校客户（就业指导场景）可享教育行业折扣，具体见商务条款。

## 4. 私有化部署报价（企业 / 高安全客户）

| 项目 | 价格（¥） | 说明 |
| --- | --- | --- |
| 一次性授权费（基础） | ¥98,000 | 含系统源码授权、部署、培训 |
| 一次性授权费（企业版） | ¥198,000 | 含组织级知识库、多租户、运营后台全量能力 |
| 年维护费 | 授权费的 15% | 含升级、补丁、故障响应（SLA 可协商） |
| 二开 / 集成 | 人天计价 | 飞书/钉钉 SSO 对接、第三方岗位源接入等 |

> 私有化交付前提：客户自有 MySQL 8.0 与 ≥16G 内存环境；提供 Docker Compose 一键部署与备份恢复脚本。

## 7. API 能力开放定价（M6，规划中——框架已定，终价待 M6 校准）

> 成本模型：单次智能分析 ≈ 3-5 次 LLM 调用 + 1 次 RAG 检索；单次模拟面试 ≈ 10-20 次 LLM 调用。定价须覆盖 LLM 成本 + 基础设施 + 毛利（≥60%）。

| 档位 | 计费方式 | 价格（¥） | 说明 |
| --- | --- | --- | --- |
| 试用 | 免费配额 | 每月 100 次分析 | 开发者体验 |
| 按量 | 单次调用 | 智能分析 ¥0.30/次、模拟面试 ¥0.80/会话、岗位匹配 ¥0.10/次 | 无订阅，先充后用 |
| 企业包 | 预付费包年 | 10 万次 ¥22,000（≈¥0.22/次） | 阶梯折扣 + 专属通道 |

> 定价依据与推导见 `docs/定价复盘.md` §2.3。

## 8. 报价流程（销售侧）

1. 确认客户类型（院校 / 培训 / 企业 / 渠道）与部署形态（SaaS / 私有化）；
2. 按上表选择档位与用户量，出初报价单；
3. 演示环境（见 `docs/演示脚本.md`）现场演示；
4. 商务谈判（折扣权限：渠道价 / 教育价 / 老客户续费价由运营负责人审批）；
5. 签约（《技术复用补充协议》已就绪）→ 运营后台 0.5 天交付上线。
