## 2. 三档定价方案（对外基线，含 M6 API 新增）

### 2.1 白标年费（SaaS，院校/培训机构）

| 档位 | 年费（¥） | 用户量 | 超出单价 | 权益要点 |
| --- | --- | --- | --- | --- |
| 基础版（free） | ¥0 | ≤ 50 | — | 试用，无白标 |
| Pro 版 | ¥9,800 | ≤ 300 | ¥20/人/年 | 完整权益 + 基础白标 |
| 企业版 | ¥29,800 | ≤ 1,000 | ¥15/人/年 | 多管理员 + 组织级知识库 + 专属支持 |
| 定制版 | 面议 | 1,000+ | — | 私有化 / 高安全 / 定制开发 |

**待 Pilot 验证**：Pro 版 ¥9,800 价格带与教育行业折扣幅度（高校就业办付费弹性通常低于培训机构）。

### 2.2 私有化授权（企业 / 高安全客户）

| 项目 | 价格（¥） | 说明 |
| --- | --- | --- |
| 基础授权 | ¥98,000 | 源码授权 + 部署 + 培训 |
| 企业版授权 | ¥198,000 | 组织级知识库 + 多租户 + 运营后台全量 |
| 年维护费 | 授权费 15% | 升级 / 补丁 / 故障响应 |
| 二开/集成 | 人天计价 | SSO 对接、第三方岗位源接入 |

**待 Pilot 验证**：私有化是否本 Pilot 期即出现需求（Pilot 建议以白标 SaaS 为主，私有化排后）。

### 2.3 API 能力开放（M6，规划中——本期定框架不定终价）

> 定价依据成本模型：单次智能分析 ≈ 3-5 次 LLM 调用 + 1 次 RAG 检索 + embedding；单次模拟面试 ≈ 10-20 次 LLM 调用。API 定价须覆盖 LLM 成本 + 基础设施 + 毛利（建议毛利率 ≥ 60%）。

| 档位 | 计费方式 | 价格（¥） | 说明 |
| --- | --- | --- | --- |
| 试用 | 免费配额 | 每月 100 次分析 | 开发者体验 |
| 按量 | 单次调用 | 智能分析 ¥0.30/次、模拟面试 ¥0.80/会话、岗位匹配 ¥0.10/次 | 无订阅，先充后用 |
| 企业包 | 预付费包年 | 10 万次 ¥22,000（≈¥0.22/次） | 阶梯折扣 + 专属通道 |

**待 M6 启动后校准**：按真实 token 用量复盘单次成本，修订单价与包年梯度。

## 4. 商业模式结论（当前判断）

1. **收入主引擎是白标年费**：重复订阅收入、边际交付成本低（配置化 0.5 天/租户），是现金流基本盘；
2. **私有化是高价低量补充**：单价高但一次性、维护费持续，适合大客户与高安全诉求，不主动推销；
3. **API 是第二曲线（M6）**：面向人才服务商，按量计费与 LLM 成本强相关，需在 M6 落地成本模型后定价；
4. **毛利率目标**：白标 SaaS ≥ 70%（去除 LLM/基建/人力后），私有化 ≥ 60%（含二开与支持）。
